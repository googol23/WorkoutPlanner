# Running subskill

Read the [running evidence register](../references/running-evidence.md) and
[Garmin running output contract](../references/running-output.md).

- Compare duration, distance, pace or speed, heart rate, time in zones, splits
  and intended versus recorded intervals. Consider terrain and weather.
  Distinguish elapsed from moving time and account for downsampled series.
- Use the athlete's actual zone boundaries before interpreting zone labels or
  setting numeric targets. Use an effort cue when recent comparable data is
  insufficient to establish a target. [G1]
- Consider recent running frequency, volume, intensity and reported recovery
  together. Favor easy work where appropriate and use recent tolerated
  workload to size a progression. Avoid fixed progression percentages or
  forcing a weekly intensity distribution on a single workout. [R1–R4]
- For an adjustment, check whether time, recovery, or scheduling warrants
  changing the work, recovery, intensity or duration. Verify the total after
  expanding repeats. Return the separate Garmin-ready JSON and direct the
  athlete to the uploader's dry-run.
